# Daawat Public Website

Static public restaurant website for Daawat, built for customer trust and Razorpay business website verification.

## Run locally

```bash
npm install
npm run dev
npm run build
```

## Deploy

Deploy the Vite build on Vercel or Netlify.

Use the deployed public website URL for Razorpay verification, for example:

- `https://daawat.vercel.app`
- `https://daawat.netlify.app`
